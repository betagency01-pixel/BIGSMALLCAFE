# The Bigg Small Cafe + Bar — website demo

A single-page demo site for The Bigg Small Cafe + Bar (Lotus Park, Wagle Estate, Thane).

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `assets/` — logo and photos

Run it locally with any static server, for example:

```bash
python -m http.server 5178
```

then open http://localhost:5178.

Note: photos and branding belong to The Bigg Small Cafe + Bar; get their approval before publishing.
